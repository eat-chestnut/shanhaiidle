# Character & Skill UI Assets Pack

本压缩包用于 Godot 4.5 项目的“人物页 / 技能页”占位资源。

## 目录结构
- assets/ui_frames/ : common_board_quality_* 作为格子背景框（按稀有度）
- assets/icons/     : icon_* 作为物品/装备/技能占位图标
- assets/backgrounds/:
  - bg_character.png  人物页背景占位
  - bg_skills.png     技能页背景占位
  - nav_placeholder.png 底部导航占位

## 稀有度框建议映射
- white  -> common_board_quality_white.png
- blue   -> common_board_quality_blue.png
- gold   -> common_board_quality_orange.png
- empty  -> common_board_quality_mask.png
