# 怪物模块后台录入指南

## 一、新增普通怪
1. 进入后台 `世界观与主线 / 怪物库`
2. 点击新增
3. 在 `基础信息` 中填写：
   - 怪物 ID
   - 名称
   - 展示名
   - 怪物类型：选择 `普通怪`
   - 所属章节
   - 族系 / 称号 / prefab_key / 图标
4. 在 `战斗数值` 中填写：
   - 等级
   - HP / ATK / DEF
   - 速度 / 移动速度
   - 攻击范围 / 攻击间隔 / 警戒范围
   - AI 类型
5. 保存

## 二、新增精英怪
1. 在 `怪物库` 新增怪物
2. `怪物类型` 选择 `精英怪`
3. 基础信息与战斗数值填写方式与普通怪一致
4. 建议在 `技能挂载` 中至少挂 1 个主动技能
5. 保存

## 三、新增 Boss
1. 在 `怪物库` 新增怪物
2. `怪物类型` 选择 `Boss`
3. 先填写基础信息和战斗数值
4. 打开 `Boss扩展`：
   - 阶段数
   - 出场文本
   - BGM / 镜头规则
   - 首通奖励组
   - 剧情标记
   - 阶段规则 / 狂暴规则 / 召唤规则 / 弱点规则
5. 保存

## 四、给怪物挂技能
1. 打开怪物编辑页
2. 切到 `技能挂载`
3. 每条技能填写：
   - `skill_id`
   - `slot_type`
   - `trigger_priority`
   - `phase_limit`（可空）
   - `sort_order`
   - `is_enabled`
4. Boss 可以挂更多 `phase_skill / ultimate`

## 五、给怪物挂掉落
1. 打开怪物编辑页
2. 切到 `掉落挂载`
3. 每条掉落挂载填写：
   - `drop_group_id`
   - 是否主掉落组
   - 排序
   - 备注
4. 怪物只挂掉落组，不在这里直接录掉落条目

## 六、在主线难度中配置怪物列表
1. 进入后台 `世界观与主线 / 主线难度`
2. 选择目标难度
3. 分别维护：
   - `普通怪列表`
   - `精英怪列表`
   - `Boss列表`
4. 每条记录填写：
   - `monster_id`
   - `weight`
   - `min_count`
   - `max_count`
   - `is_enabled`
   - `sort_order`
   - `remark`

## 七、录入规则提醒
- 普通怪区块只能选普通怪
- 精英怪区块只能选精英怪
- Boss 区块只能选 Boss
- 一个战斗难度必须至少配置普通怪、精英怪、Boss
- 序章、终章不要录战斗难度和怪物列表

## 八、常见错误
- 误把 Boss 放进精英怪区块：会在保存时校验失败
- 未填写 `monster_id`：不会保存
- `max_count < min_count`：不会保存
- 怪物所属章节与主线难度章节不一致：导入时会报错
